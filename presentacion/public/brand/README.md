# Official NTT DATA logo

The local asset is the SVG served in the header of the official NTT DATA global website:

https://www.nttdata.com/global/en/-/media/assets/images/header_logo.svg?iar=0&rev=010dc1bd851f4d2aaaaf407cf338776b

It is kept unchanged at:

```text
ntt-data-logo.svg
```

`presentation.meta.logo` is configured to use this local file. A text fallback remains for cases where the image cannot load.

Requirements:

- preserve the original aspect ratio;
- do not recolor or redraw the logo;
- retain adequate clear space;
